# Cursor Game 🎯

A fun cursor-based target clicking game built with HTML, CSS, and JavaScript.

## How to Play

1. Open `index.html` in your web browser
2. Click the "Start Game" button
3. Use your cursor to click on the red targets that appear randomly
4. Score as many points as possible within 30 seconds
5. Targets disappear after 3 seconds if not clicked

## Features

- Responsive cursor-based gameplay
- Real-time scoring system
- 30-second timer
- Randomly spawning targets
- Smooth animations and hover effects
- Game over screen with final score
- Play again functionality

## Getting Started

Simply open the `index.html` file in any modern web browser to start playing!

## Game Rules

- Each target clicked = 1 point
- Targets spawn every 1.5 seconds
- Targets auto-disappear after 3 seconds
- Game lasts 30 seconds
- Try to achieve the highest score possible!
